Claude 与 Codex 安装教程

AI 编程助手已经成为开发者日常工具链中不可或缺的一环。本文详细介绍如何安装和配置目前最主流的两款 AI 编程工具：Anthropic 的 Claude（Claude Desktop + Claude Code CLI）和 OpenAI 的 Codex（Codex CLI / Codex 桌面应用）。

无论你用的是 macOS、Windows 还是 Linux，跟着走一遍就能跑起来。

准备工作

在开始之前，请确认你具备以下条件：

  • 一台 macOS、Windows 或 Linux 电脑
  • 稳定的网络环境（部分服务需要代理）
  • Python 3.8+（Codex CLI 依赖）
  • Node.js 18+（Claude Code 依赖）
  • 对应平台的 API Key 或订阅账号

如果你的网络无法直连 OpenAI / Anthropic 服务，请提前准备好代理工具，并确保终端环境变量中正确设置了 HTTP_PROXY 和 HTTPS_PROXY。

第一部分：安装 Claude

Claude 目前提供两种使用方式：桌面应用（Claude Desktop）和命令行工具（Claude Code CLI）。桌面应用适合日常对话，Claude Code 则面向编程场景，可以直接在终端里读写文件、执行命令。

1.1 安装 Claude Desktop

macOS

  1. 打开浏览器，访问 Claude 官网：https://claude.ai
  2. 点击右上角 “Download” 或直接访问 https://claude.ai/download
  3. 下载 .dmg 文件，双击挂载
  4. 将 Claude 拖入 Applications 文件夹
  5. 打开 Claude，使用 Anthropic 账号登录（可用 Google / Apple 账号快捷登录）

Windows

  1. 访问 https://claude.ai/download
  2. 下载 Windows 版安装包（.exe）
  3. 双击运行安装程序，按提示完成安装
  4. 打开 Claude，登录你的 Anthropic 账号

Claude Desktop 支持 Mac（Apple Silicon + Intel）和 Windows 10/11。Linux 暂无官方桌面客户端，建议使用网页版 https://claude.ai 或 Claude Code CLI。

Claude Code 是 Anthropic 官方推出的终端编程工具，可以在你的项目目录中直接与 Claude 交互，支持文件读写、命令执行、Git 操作等。

2.2 安装 Codex 桌面应用

OpenAI 也提供了 Codex 的桌面应用，适合不喜欢终端操作的用户。

macOS

  1. 访问 https://openai.com/codex 下载页面
  2. 下载 .dmg 文件
  3. 双击挂载，拖入 Applications
  4. 打开应用，登录 ChatGPT 账号或配置 API Key

Windows

  1. 在下载页面选择 Windows 版安装包
  2. 运行 .exe 安装程序
  3. 打开应用，完成登录

Codex 桌面应用的界面更直观，适合做代码审查和项目管理，但功能上 CLI 版本更灵活、更适合深度编程。

这些文件会让 AI 在每次会话启动时自动读取，省去重复说明的麻烦。

Q1 安装时报权限错误？

Q2 登录时浏览器没反应？

确保终端能正常打开浏览器。在无图形界面的服务器上，可以手动复制终端中显示的授权 URL 到本地浏览器。

Q3 Claude Code 和 Codex 能同时用吗？

可以。两者完全独立，互不干扰。很多人会根据任务特点交替使用：Claude Code 做前端和 TypeScript，Codex 做后端和 Python。

Q4 每月费用多少？

  • Claude：免费版有限额，Pro 订阅 20 美元/月，包含 Claude Code 使用额度
  • Codex：ChatGPT Plus 20 美元/月，Pro 200 美元/月，API 则按 token 计费

Q5 终端报 Node 版本过低？

开发商 Anthropic OpenAI

桌面应用 Claude Desktop Codex 桌面应用
CLI 工具 Claude Code Codex CLI
认证方式 Anthropic 账号 / API Key ChatGPT 订阅 / API Key
配置文件 CLAUDE.md AGENTS.md
适合场景 前端 / TypeScript / 长上下文 后端 / Python / 自动化

两款工具各有侧重，选择哪一款取决于你的技术栈和使用习惯。如果条件允许，建议都装上，在实际项目中对比体验，找到最顺手的那一个。

AI 编程助手不是替代你写代码，而是帮你把重复劳动交给机器，把思考留给真正有价值的问题。装好工具，开始干活吧。
