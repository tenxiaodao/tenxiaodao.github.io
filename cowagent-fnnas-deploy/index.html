飞牛 NAS 部署 CowAgent 并开放局域网访问

环境：飞牛 NAS（主机名 fnnas，普通用户 FNNAS，Python 3.11）
CowAgent 源码位于 /root/CowAgent/，Web 控制台端口 9899
所有命令在 NAS 上以 root 运行（sudo -i）

CowAgent 即 chatgpt-on-wechat（命令名 cow，包名 cowagent），是一个可以把 AI 接入微信/飞书的聊天机器人框架，支持多模型后端（智谱 GLM、OpenAI 等）、技能扩展、Web 控制台等功能。飞牛 NAS 没有自带浏览器，Web 控制台默认只监听 127.0.0.1，本机访问不了，所以需要把监听地址改成 0.0.0.0，让局域网内的电脑/手机能通过浏览器访问。

本文从零开始记录完整部署流程：获取源码、安装依赖、初始配置、用 systemd 托管服务、开放局域网访问，最后附常见坑和速查命令。

为什么选源码部署

项目提供了一个 docker-compose.yml，但引用的预构建镜像只有 amd64 版本。飞牛 NAS 如果是 ARM 架构（aarch64），Docker 方式会触发平台不匹配警告——虽然可以通过 platform: linux/amd64 模拟运行，或本地 docker build 自建 arm64 镜像，但都比较折腾，性能也打折。

源码部署更直接：克隆代码、pip install -e . 装好就能用，改配置方便，后续装技能、改源码都即时生效。所以本次走的是源码 + editable 安装方式。

3. 开放局域网访问

默认配置没有 web_host 字段，因此监听 127.0.0.1，只能本机访问。需要在 config.json 里加两个字段：

  • web_host: 0.0.0.0 —— 监听所有网卡
  • web_password: 自己设一个登录密码

终端自动换行会把长命令断成两行导致报错。如果复制粘贴失败，改用反斜杠续行，或直接用 vi 手动编辑。

验证是否改成功：

看到 "web_host": "0.0.0.0" 即成功。

替代做法：vi 手动编辑

  1. 找到 "web_port": 9899 那一行
  2. 按 i 进入编辑模式
  3. 在 "web_port" 前面加上 "web_host": "0.0.0.0", "web_password": "你的密码",
  4. 按 Esc，输入 :wq 回车保存

飞牛防火墙放行

如果上一步做完仍然从局域网访问不了，检查 fnOS 防火墙是否放行了 9899 端口：

fnOS 大部分版本默认不拦局域网端口，这一步通常不需要。但如果你在飞牛 Docker 网络或虚拟接口环境下部署，可能需要手动放行。

4. 配置 systemd 托管

CowAgent 需要长期运行，最好交给 systemd 管理——开机自启、崩溃自动重启、日志统一收集。

4.1 创建服务文件

几个关键点：

  • WorkingDirectory 设为 /root/CowAgent，确保 config.json 和源码能被找到
  • ExecStart 用 venv 里的 Python，而不是系统 Python，确保依赖正确加载
  • Restart=always + RestartSec=10：进程崩溃后 10 秒自动拉起，避免重启风暴
  • 日志统一写到 /var/log/cowagent.log

然后在电脑/手机浏览器打开：

例如 NAS IP 是 192.168.1.100，就访问 http://192.168.1.100:9899，输入第 3 步设的 web_password 登录。

登录后就能在 Web 控制台里直接跟 AI 对话，也可以从这里安装/管理技能（cow skill install ...）。

如果页面打不开，依次排查：

  1. systemctl status cowagent 确认服务在跑
  2. grep web_host /root/CowAgent/config.json 确认是 0.0.0.0
  3. hostname -I 确认 IP 没错
  4. 浏览器和 NAS 在同一局域网（同网段）

常见坑

现象 原因 解决
python3 -c "..." 报 IndentationError 终端自动换行把命令截断、加了缩进 改用 sed 或 vi
heredoc cat > /tmp/fix.py 卡住 进了输入模式 Ctrl+C 退出，改用 sed
sed: no input files / Permission denied 命令被换行断成两行 用 sudo + 反斜杠续行，或 cd /root/CowAgent 后对 config.json 操作
cow skill install ... 报 Permission denied 访问 /root/CowAgent/cli/__init__.py cow 是 editable 安装，去 /root/CowAgent/ 找源码；普通用户 FNNAS 没权限读 /root 用 sudo -i 切到 root 再运行 cow
Web 控制台打不开 web_host 没改成 0.0.0.0，或 systemd 服务没启动 grep web_host config.json 确认配置，systemctl status cowagent 确认服务在跑
pip install -e . 报权限错误 没用 venv，直接装到了系统 Python 确保先 source venv/bin/activate
浏览器能打开但提示密码错误 web_password 没设，或设了但没重启服务 systemctl restart cowagent
飞牛 NAS 重启后服务没自动起来 systemctl enable 没执行 systemctl enable cowagent
页面能打开但 AI 不回复 API key 没填对，或 bot_type / model 配错 grep -E 'bot_type|model|api_key' config.json 检查，对照第 2 节示例
日志报 Address already in use 9899 端口被占 lsof -i:9899 找到占用进程，kill 掉或改 web_port
